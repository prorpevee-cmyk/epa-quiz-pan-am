# Quiz EPA · Pan Am

Prévia para avaliação da equipe: https://prorpevee-cmyk.github.io/epa-quiz-pan-am/

São seis perguntas e três perfis de planejamento. O botão Refazer o quiz permite testar outras combinações. As respostas do quiz ficam apenas na memória do navegador.

## Testar os perfis

- Explorando o caminho: última alternativa em todas as perguntas.
- Organizando o plano: segunda alternativa em todas as perguntas.
- Preparando a conversa: primeira alternativa em todas as perguntas.

Os três pontos de orientação variam conforme as respostas. O quiz orienta planejamento e não confirma elegibilidade para certificação.

O botão final leva a roadshow.html. Os formulários dessa página enviam as inscrições ao Google Forms já integrado à campanha; se enviar um teste, identifique-o claramente como TESTE.

## Hospedagem

Arquivos estáticos, sem instalação ou compilação. GitHub Pages publica a raiz da branch main. Para outra hospedagem, transfira os arquivos mantendo-os no mesmo diretório.
